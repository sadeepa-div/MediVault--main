MediVault – Digital Medicine Management System

Tech Stack
- React + Vite
- Node.js
- Express.js
- MySQL
- JWT
- bcrypt
- Google OAuth

Features
- User registration and login
- Google login
- Role-based access
- Medicine search
- Medicine management
- Pharmacy management
- Stock management
- User profile management
- Dashboard
- Protected admin routes

Roles
User:
- Search medicines
- View pharmacy availability
- Manage profile

Admin:
- All user features
- Manage medicines
- Manage pharmacies
- Manage stock

How to Run
1. Import database/schema.sql
2. Configure Backend/.env
3. Run backend
4. Run frontend
